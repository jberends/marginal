Marginal

Privacy policy

Effective 29 July 2026

Marginal is a markdown editor for macOS. This policy is short because there is little to say: Marginal collects no data.

What Marginal collects

Nothing. Marginal has no analytics, no telemetry, no crash reporting, no accounts, and no advertising. It makes no network connections on its own.

Checking for updates

If you choose Check for Updates in the app menu, Marginal makes one request to GitHub's public API to read the latest release number. This happens only when you ask, sends nothing beyond a standard HTTP request, and stores nothing. GitHub's handling of that request is covered by GitHub's privacy statement.

Your documents

Documents are plain markdown files on your Mac. They are read and written only where you choose to open and save them, and they never leave your machine. Marginal runs inside the macOS App Sandbox, which limits its file access to exactly the files you select.

App Store distribution

If you install Marginal through the Mac App Store, Apple processes the download and any associated receipt under its own privacy policy. None of that information reaches the developer.

Changes

If a future version of Marginal ever changes any of the above — for example, an optional feature that talks to a service you configure — this policy will be updated first, and the feature will be off by default.

Contact

Questions? Open an issue at github.com/jberends/marginal.
