Marginal's single button component — use it for every action, from marketing CTAs to toolbar controls.

```jsx
<Button variant="primary" size="lg" href="#download">Download for macOS</Button>
<Button variant="secondary">View on GitHub</Button>
<Button variant="ghost" size="sm">Copy as HTML</Button>
```

Variants: `primary` (violet #8E1FCB, one per view), `secondary` (paper + hairline border), `ghost` (transparent, muted label).
Sizes: `sm` 13px / `md` 14px / `lg` 16px. Hover darkens; press scales to 0.985 — never bounce.
