# UI kit — marginal.app

The marketing homepage, composed entirely from design-system components.

**Files**
- `index.html` — the full page
- `Sections.jsx` — Hero, Features, PlainText, Shortcuts, Download, plus `MiniEditor`
  (a live recreation of the app used inside the hero's ScreenshotFrame)

**Interactive** — the hero's "Preview dark" chip flips the framed product shot between
light and dark without changing the page around it.

**Content rules** — one violet primary button above the fold, sentence case, facts only.
Every claim on the page comes from the product brief; nothing is invented.
