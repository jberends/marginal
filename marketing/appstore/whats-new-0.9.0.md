# App Store “What’s New” — Marginal 0.9.0

Paste the block below into App Store Connect ▸ your 0.9.0 version ▸ **What’s New in This
Version**. It is 1,180 characters, inside the 4,000-character limit, and avoids the things
App Review rejects notes for: no version numbers in the first line, no “bug fixes and
performance improvements” alone, no mention of other platforms or of pricing.

---

Marginal 0.9.0 is a typography release: the same fast, file-first Markdown editor, now far
nicer to read and to look at for hours.

TYPOGRAPHY
• A new typeface and a reworked vertical rhythm, so long documents read comfortably instead
  of feeling cramped.
• Headings sit closer to the text they introduce, with more air above them.
• Links use Marginal’s accent colour with a fine underline.

WRITING
• Bare URLs and email addresses become links as you type them — no extra syntax.
• ⌘-click opens a link in your browser; links to a heading jump straight to it.
• Straight quotes, ellipses and dashes display as proper typographic characters, and HTML
  entities such as &copy; show as ©. Your file keeps exactly what you typed.
• Word and character counts in the status bar, including your position in the document and
  the size of the selection.

FILES
• Open Recent, plain-text (.txt) files, and drag-and-drop onto the app icon.
• Hold ⌘W or ⌘Q to close or quit without saving.

FIXES
• Nested blockquotes, and lists and code blocks written inside a blockquote, now render
  correctly.
• Bold combined with strikethrough renders as both.
• Text selection is visible inside code blocks.

## Review notes (App Store Connect ▸ App Review Information)

Nothing in this release changes data handling, entitlements, or network use. Marginal reads
and writes only the documents the user opens, stays sandboxed, and makes no network requests
apart from the existing manual “Check for Updates” action.
