# Image Insertion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let the user embed images into a markdown document by paste, screenshot, or drag — buffered to a temp folder while the document is untitled, relocated into a sibling `<doc>.assets/` folder with relative references on save; images dragged from an existing file on disk are referenced by absolute path and never copied.

**Architecture:** Marginal edits *literal markdown source* in a single `NSTextView` (`MarkdownTextView`); display styling is applied as length-preserving attributes over that source and re-applied on every edit/selection. This feature adds (1) recognition of `![alt](path)` image markup in the parser, (2) a `DocumentImageStore` that owns the temp/assets file lifecycle, (3) paste + drag entry points that write image bytes and insert markdown at the caret, (4) a save-time relocation+rewrite hook that keeps the open editor in sync, (5) `<img>` HTML/PDF export, and finally (6) inline rendering of the image in the editor via the existing `MarkdownLayoutManager` custom-drawing technique (the same attribute-driven `drawBackground` path that already draws quote bars, bullets, and emoji glyphs — the codebase deliberately uses no `NSTextAttachment`).

**Tech Stack:** Swift + AppKit (macOS), TextKit 1 (`NSLayoutManager` subclass), `NSDocument`, `NSPasteboard`/drag-and-drop, XCTest. Build/test via xcodebuild; the app is sandboxed.

## Global Constraints

- **Language/UI:** Swift + AppKit only. No third-party dependencies (the project has none). Match existing file style.
- **Editor architecture is fixed:** the text storage always holds literal markdown source; all display is length-preserving attributes re-applied in `DocumentViewController.restyle(cursorLocation:)`. Never delete or insert characters to achieve a display effect — hide with the shrunk `hiddenFont` technique used by `MarkdownStyler` for link delimiters.
- **No `NSTextAttachment`.** Inline visuals are drawn in `MarkdownLayoutManager.drawBackground(forGlyphRange:at:)`, keyed off custom `NSAttributedString.Key`s, with reserved layout space. Follow the existing emoji-glyph pattern (`EmojiGlyphInfo`, `MarkdownLayoutManager.swift`).
- **Sandbox:** `com.apple.security.app-sandbox = true`, `com.apple.security.files.user-selected.read-write = true`. Writing beside a *saved* document's `.md` is inside the granted security scope. An **untitled** document has no folder, so managed images must buffer under `FileManager.default.temporaryDirectory`.
- **Managed vs linked rule (threads the whole feature):**
  - *Managed* image = raw image bytes arrived via paste/screenshot or an image-**data** drag (no source file). Marginal owns its file. Untitled → written to the document's temp dir with an absolute path in the markdown. Saved → written directly into `<doc>.assets/` with a relative path. On first save of an untitled doc, managed temp files are moved into `<doc>.assets/` and their paths rewritten to relative.
  - *Linked* image = an existing image **file** dragged in from Finder. Referenced by **absolute** path, never copied, never rewritten.
- **Filenames for managed images:** `pasted-YYYYMMDD-HHMMSS.<ext>` (local time). On a same-second collision, append `-2`, `-3`, … before the extension. Always encode to **PNG** when the source is raw bitmap/TIFF data; preserve the original extension only when the bytes are already a recognised compressed format (png/jpg/jpeg/gif/heic/webp).
- **Assets folder:** for a document saved as `…/MyNote.md`, the folder is `…/MyNote.assets/`. Relative references are `MyNote.assets/pasted-….png`.
- **UTF-8 only** for document text (unchanged).
- **Encoding paths in markdown:** paths with spaces must be percent-encoded in the URL portion only where required for export; the *editor source* keeps the human-readable path. (Filenames generated by this feature contain no spaces, so this only matters for linked absolute paths — see Task 6.)
- **TDD, frequent commits.** Test target `MarginalTests`. Run the full suite with:
  `xcodebuild -project Marginal.xcodeproj -scheme Marginal test`
  Scope a single class with `-only-testing:MarginalTests/<ClassName>`. A full run is 7–10 min — run it in the background and watch the log; never run two xcodebuild processes at once (they corrupt the shared module cache).
- **Design system:** any UI weight is **semibold (600)**, never 700.
- **Post-mortem lessons that bind this plan:** a render harness is not usage. Every task that changes what is *drawn* or how a *keystroke* behaves (Tasks 3, 4, 5, 7, 8, 9) MUST be verified by launching the real app (use the `run` skill) in addition to tests. Phase 1 ends at a shippable build; get it into the user's hands before starting Phase 2.

```swift
/// Matches CommonMark image syntax `![alt](path)`. Alt may be empty; path is the raw
/// text between the parentheses (not URL-decoded — the editor stores human-readable paths).
static func parseImages(in text: String) -> [ImageSpan] {
    guard let regex = try? NSRegularExpression(pattern: #"!\[([^\]]*)\]\(([^)]+)\)"#) else {
        return []
    }
    let ns = text as NSString
    return regex.matches(in: text, range: NSRange(location: 0, length: ns.length)).compactMap { m in
        guard let full = Range(m.range, in: text),
              let alt = Range(m.range(at: 1), in: text),
              let path = Range(m.range(at: 2), in: text) else { return nil }
        return ImageSpan(fullRange: full, altRange: alt, pathRange: path,
                         altText: String(text[alt]), path: String(text[path]))
    }
}
```
Then in `parseLinks(in:)`, after computing each match's `[` start index, skip the match when the preceding character is `!`:
```swift
// inside the matches loop, before appending the LinkSpan:
let openBracket = /* Range(m.range, in: text)!.lowerBound — the '[' of this link */
if openBracket > text.startIndex {
    let prev = text.index(before: openBracket)
    if text[prev] == "!" { continue }   // belongs to an image, not a link
}
```
(Wire `openBracket` to whatever local the existing loop already has for the match's lower bound; do not restructure the rest of `parseLinks`.)

  ```swift
  final class DocumentImageStore {
      /// Per-document temp buffer for managed images while the document is untitled.
      /// Lazily created under FileManager.default.temporaryDirectory.
      let tempDirectory: URL

      init(fileManager: FileManager = .default)

      /// `pasted-YYYYMMDD-HHMMSS.<ext>`, uniquified within `directory` by appending -2, -3, …
      func uniqueFilename(ext: String, now: Date, in directory: URL) -> String

      /// Writes managed bytes into `tempDirectory`, returns the file URL. `ext` already chosen by caller.
      func writeToTemp(data: Data, ext: String, now: Date) throws -> URL

      /// Writes managed bytes directly into `assetsDir` (created if needed), returns the file URL.
      func write(data: Data, ext: String, now: Date, into assetsDir: URL) throws -> URL

      /// True when `url` lives inside this store's tempDirectory (i.e. a managed temp file).
      func isManagedTemp(_ url: URL) -> Bool

      /// Moves each managed temp file into `assetsDir` (created if needed). Returns old→new URL map.
      /// Skips URLs not under tempDirectory. On name clash in assetsDir, uniquifies.
      func relocateTempFiles(_ urls: [URL], into assetsDir: URL, now: Date) throws -> [URL: URL]

      /// Removes tempDirectory. Call when the document closes.
      func cleanupTemp()
  }
  ```

- [ ] **Step 3: Implement `DocumentImageStore`**

```swift
import AppKit

@MainActor
final class DocumentImageStore {
    let tempDirectory: URL
    private let fm: FileManager

    init(fileManager: FileManager = .default) {
        self.fm = fileManager
        self.tempDirectory = fileManager.temporaryDirectory
            .appendingPathComponent("marginal-images-\(UUID().uuidString)", isDirectory: true)
    }

    private func ensureTemp() throws {
        if !fm.fileExists(atPath: tempDirectory.path) {
            try fm.createDirectory(at: tempDirectory, withIntermediateDirectories: true)
        }
    }

    func uniqueFilename(ext: String, now: Date, in directory: URL) -> String {
        let fmt = DateFormatter()
        fmt.dateFormat = "yyyyMMdd-HHmmss"
        fmt.locale = Locale(identifier: "en_US_POSIX")
        let stamp = fmt.string(from: now)
        let base = "pasted-\(stamp)"
        var candidate = "\(base).\(ext)"
        var n = 2
        while fm.fileExists(atPath: directory.appendingPathComponent(candidate).path) {
            candidate = "\(base)-\(n).\(ext)"
            n += 1
        }
        return candidate
    }

    func writeToTemp(data: Data, ext: String, now: Date) throws -> URL {
        try ensureTemp()
        let name = uniqueFilename(ext: ext, now: now, in: tempDirectory)
        let url = tempDirectory.appendingPathComponent(name)
        try data.write(to: url)
        return url
    }

    func write(data: Data, ext: String, now: Date, into assetsDir: URL) throws -> URL {
        if !fm.fileExists(atPath: assetsDir.path) {
            try fm.createDirectory(at: assetsDir, withIntermediateDirectories: true)
        }
        let name = uniqueFilename(ext: ext, now: now, in: assetsDir)
        let url = assetsDir.appendingPathComponent(name)
        try data.write(to: url)
        return url
    }

    func isManagedTemp(_ url: URL) -> Bool {
        url.standardizedFileURL.path.hasPrefix(tempDirectory.standardizedFileURL.path + "/")
    }

    func relocateTempFiles(_ urls: [URL], into assetsDir: URL, now: Date) throws -> [URL: URL] {
        var map: [URL: URL] = [:]
        for url in urls where isManagedTemp(url) {
            if !fm.fileExists(atPath: assetsDir.path) {
                try fm.createDirectory(at: assetsDir, withIntermediateDirectories: true)
            }
            let name = uniqueFilename(ext: url.pathExtension, now: now, in: assetsDir)
            let dest = assetsDir.appendingPathComponent(name)
            try fm.moveItem(at: url, to: dest)
            map[url] = dest
        }
        return map
    }

    func cleanupTemp() {
        try? fm.removeItem(at: tempDirectory)
    }
}
```

Add a `DocumentImageStore` property (lazily created; store it as `private lazy var imageStore = DocumentImageStore()`), then:
```swift
/// Chooses the on-disk destination by document state and returns the markdown path to embed.
/// Managed image: temp+absolute while untitled, <doc>.assets/name+relative while saved.
func insertImageData(_ data: Data, sourceExtension: String, now: Date) -> String? {
    let ext = Self.normalizedImageExtension(sourceExtension)
    do {
        if let fileURL = document?.fileURL {
            let docName = fileURL.deletingPathExtension().lastPathComponent
            let assetsDir = fileURL.deletingLastPathComponent()
                .appendingPathComponent("\(docName).assets", isDirectory: true)
            let written = try imageStore.write(data: data, ext: ext, now: now, into: assetsDir)
            return "\(docName).assets/\(written.lastPathComponent)"
        } else {
            let written = try imageStore.writeToTemp(data: data, ext: ext, now: now)
            return written.path
        }
    } catch {
        NSSound.beep()
        return nil
    }
}

/// PNG for raw bitmap/tiff; keep known compressed formats as-is.
static func normalizedImageExtension(_ ext: String) -> String {
    let known: Set<String> = ["png", "jpg", "jpeg", "gif", "heic", "webp"]
    let lower = ext.lowercased()
    return known.contains(lower) ? lower : "png"
}
```

```swift
func markdownTextViewInsertPastedImage(_ textView: MarkdownTextView) -> Bool {
    let pb = NSPasteboard.general
    // Prefer file promises / file URLs handled by the drag path; here handle raw image data.
    guard let (data, ext) = Self.imageDataFromPasteboard(pb) else { return false }
    guard let path = insertImageData(data, sourceExtension: ext, now: Date()) else { return true }
    let markup = "![](\(path))"
    let sel = textView.selectedRange()
    if textView.shouldChangeText(in: sel, replacementString: markup) {
        textView.insertText(markup, replacementRange: sel)
        textView.didChangeText()
    }
    return true
}

/// Returns (bytes, extension) for the best image on the pasteboard, or nil.
static func imageDataFromPasteboard(_ pb: NSPasteboard) -> (Data, String)? {
    if let png = pb.data(forType: .png) { return (png, "png") }
    if let tiff = pb.data(forType: .tiff),
       let rep = NSBitmapImageRep(data: tiff),
       let png = rep.representation(using: .png, properties: [:]) {
        return (png, "png")
    }
    // A file URL to an image counts as a paste of an existing file → treat as managed copy.
    if let url = NSURL(from: pb) as URL?,
       ["png","jpg","jpeg","gif","heic","webp"].contains(url.pathExtension.lowercased()),
       let data = try? Data(contentsOf: url) {
        return (data, url.pathExtension)
    }
    return nil
}
```

```swift
func prepareForSave(to targetURL: URL, now: Date) {
    let docName = targetURL.deletingPathExtension().lastPathComponent
    let assetsDir = targetURL.deletingLastPathComponent()
        .appendingPathComponent("\(docName).assets", isDirectory: true)

    let text = textView.string
    let spans = MarkdownParser.parseImages(in: text)
    // Collect managed temp URLs referenced in the document.
    let managed = spans.compactMap { span -> (ImageSpan, URL)? in
        let url = URL(fileURLWithPath: span.path)
        return imageStore.isManagedTemp(url) ? (span, url) : nil
    }
    guard !managed.isEmpty else { return }

    let moveMap: [URL: URL]
    do {
        moveMap = try imageStore.relocateTempFiles(managed.map { $0.1 }, into: assetsDir, now: now)
    } catch {
        NSSound.beep()
        return
    }

    // Rewrite paths back-to-front so earlier ranges stay valid.
    var mutable = text
    for (span, oldURL) in managed.sorted(by: { $0.0.pathRange.lowerBound > $1.0.pathRange.lowerBound }) {
        guard let newURL = moveMap[oldURL] else { continue }
        let relative = "\(docName).assets/\(newURL.lastPathComponent)"
        mutable.replaceSubrange(span.pathRange, with: relative)
    }

    // Keep the open editor and the document text in agreement with what we write.
    textView.string = mutable
    document?.text = mutable
    restyle(cursorLocation: textView.selectedRange().location)
}
```
(If `restyle(cursorLocation:)` has a different exact name/signature, use the one in `DocumentViewController`.)

```swift
/// HTML for the pasteboard: like MarkdownHTMLRenderer.html, but every local <img> is inlined
/// as a data: URI so the copied fragment is self-contained.
func htmlForCopy(of markdown: String) -> String {
    var html = MarkdownHTMLRenderer.html(fromMarkdown: markdown)
    let base = document?.fileURL?.deletingLastPathComponent()
    for span in MarkdownParser.parseImages(in: markdown) {
        let encodedSrc = span.path.addingPercentEncoding(withAllowedCharacters: .urlPathAllowed) ?? span.path
        let resolved: URL
        if span.path.hasPrefix("/") { resolved = URL(fileURLWithPath: span.path) }
        else if let base { resolved = URL(fileURLWithPath: span.path, relativeTo: base) }
        else { continue }
        guard let data = try? Data(contentsOf: resolved) else { continue }
        let mime = Self.mimeType(forExtension: resolved.pathExtension)
        let dataURI = "data:\(mime);base64,\(data.base64EncodedString())"
        html = html.replacingOccurrences(of: "src=\"\(encodedSrc)\"", with: "src=\"\(dataURI)\"")
    }
    return html
}

static func mimeType(forExtension ext: String) -> String {
    switch ext.lowercased() {
    case "png": return "image/png"
    case "jpg", "jpeg": return "image/jpeg"
    case "gif": return "image/gif"
    case "heic": return "image/heic"
    case "webp": return "image/webp"
    default: return "application/octet-stream"
    }
}
```

```swift
@MainActor
final class ImageCache {
    static let shared = ImageCache()
    private struct Key: Hashable { let path: String; let mtime: TimeInterval }
    private var cache: [Key: NSImage] = [:]

    func image(at url: URL) -> NSImage? {
        let mtime = (try? url.resourceValues(forKeys: [.contentModificationDateKey]).contentModificationDate)?.timeIntervalSince1970 ?? 0
        let key = Key(path: url.standardizedFileURL.path, mtime: mtime)
        if let hit = cache[key] { return hit }
        guard let img = NSImage(contentsOf: url) else { return nil }
        cache[key] = img
        return img
    }
}
```
