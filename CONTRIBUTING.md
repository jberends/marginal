# Contributing to Marginal

Thanks for your interest in contributing! Marginal aims to stay lean and focused — please keep that in mind before proposing large features.

## Before you start

- **Open an issue first** for anything beyond a small fix, so we can discuss approach before you invest time.
- **Check existing issues and PRs** (open and closed) to avoid duplicating work.
- Marginal is deliberately scoped: no project/folder management, no plugin system, no feature creep. If a proposal expands scope significantly, expect pushback or a request to keep it as a separate project.

## Development setup

Details will be added once the Xcode project is scaffolded.

## Pull requests

- Keep PRs focused on one change.
- Describe the problem you're solving, not just what you changed.
- Add tests where practical.
- Be patient — this is maintained on a best-effort basis.

This project follows the [Code of Conduct](CODE_OF_CONDUCT.md). Please read it before contributing.
